PDV (Ponto de Venda)

Tudo sobre vendas no sistema

Como realizar uma venda

  1. Acesse PDV no menu lateral.
  2. Digite o código de barras, SKU ou nome do produto no campo de busca.
  3. Selecione o produto na lista de resultados para adicioná-lo ao carrinho.
  4. Repita até adicionar todos os itens desejados.
  5. Clique em Finalizar Venda.
  6. Escolha a forma de pagamento e confirme.

Venda com estoque negativo

Caso um produto esteja sem estoque, o sistema exibirá um aviso e solicitará confirmação para prosseguir. É possível vender mesmo com saldo negativo.

Descontos

No carrinho, é possível aplicar desconto percentual ou por valor em cada item individualmente.

Estoque

Gerenciamento de produtos

Visualizar produtos

A página de estoque exibe todos os produtos cadastrados. Use os filtros por categoria, status e busca para encontrar produtos específicos.

Cadastrar / Editar produto

  1. Clique em + Novo Produto para cadastrar.
  2. Preencha os campos obrigatórios (nome, quantidade, preço).
  3. O campo SKU deve ter exatamente 9 dígitos numéricos.
  4. Para editar, clique no produto na tabela e depois em Editar.
  5. É possível adicionar uma URL de imagem para o produto — o preview aparece no topo do formulário.

Custo Unitário

O campo Custo Unitário é usado para calcular a margem de lucro e o lucro total nas vendas. Se não for preenchido, o sistema estima 70% do preço de venda como custo.

Excluir produto

Na tela de detalhes do produto, clique em Excluir e confirme a ação.

Gerenciar categorias

Clique no ícone de engrenagem ao lado do filtro de categorias para abrir o painel de configurações do estoque. Lá é possível ativar/desativar colunas da tabela e gerenciar categorias (adicionar ou excluir).

Entrada de Produtos

Registrar novos produtos no estoque

Registrar entrada

  1. Acesse Entrada no menu lateral.
  2. Preencha os dados do produto (nome, quantidade, preço de custo, etc.).
  3. O campo SKU deve ter 9 dígitos numéricos.
  4. Selecione a categoria e fornecedor.
  5. Clique em Adicionar ao Lote para incluir na lista de entrada.
  6. Após adicionar todos os itens, clique em Finalizar Entrada.

Ao finalizar, todos os produtos são cadastrados no estoque automaticamente.

Etiqueta de Precificação

Impressão de etiquetas de preço

Gerar etiquetas de preço

  1. Acesse Etiqueta Precificação no menu.
  2. Selecione produtos usando os filtros de busca.
  3. Marque os produtos desejados e clique em Gerar Etiquetas.
  4. As etiquetas são exibidas para impressão com nome, preço e código de barras.

Etiqueta de Prateleira

Impressão de etiquetas de prateleira

Gerar etiquetas de prateleira

  1. Acesse Etiqueta Prateleira no menu.
  2. Busque e selecione os produtos.
  3. Clique em Gerar Etiquetas para imprimir.

Relatórios

Análise de dados do sistema

Relatório de vendas

Filtre por período e visualize o resumo de vendas, incluindo valores, formas de pagamento e produtos mais vendidos.

Exportar CSV

Na página de estoque, use o botão Exportar CSV para baixar uma planilha com todos os produtos, incluindo custos e lucros.

Histórico de Vendas

Consulta de vendas realizadas

Consultar vendas realizadas

  1. Acesse Histórico de Vendas no menu.
  2. Use os filtros por data, forma de pagamento ou busca textual.
  3. Clique em uma venda para ver os detalhes completos.
  4. É possível estornar uma venda se necessário.

Contas a Pagar

Gerenciamento financeiro

Gerenciar contas

  1. Acesse Contas a Pagar no menu.
  2. Clique em + Nova Conta para cadastrar.
  3. Preencha descrição, valor, vencimento e categoria.
  4. Use os filtros para visualizar contas pendentes, pagas ou vencidas.
  5. Clique em uma conta para marcar como paga ou editar.

Importar Fornecedor

Importação em lote de produtos

Importar produtos do fornecedor

  1. Acesse Importar Fornecedor no menu.
  2. Faça upload do arquivo CSV ou XML do fornecedor.
  3. O sistema processa e exibe os produtos para revisão.
  4. Confirme a importação para adicionar os produtos ao estoque.

Endereçar Produto

Atribuir localização física no depósito

Atribuir localização física

  1. Acesse Endereçar Produto no menu.
  2. Busque o produto e selecione o endereço (corredor, prateleira, nível, posição).
  3. Confirme para salvar a localização.

Criar Endereço

Cadastrar novas localizações

Cadastrar novos endereços

  1. Acesse Criar Endereço no menu.
  2. Defina o depósito, corredor, prateleira, nível e posição.
  3. Clique em Criar para adicionar ao sistema.

Dashboard

Visão geral do negócio

Visão geral

O dashboard exibe:

  • Faturamento diário e mensal
  • Lucro líquido (considerando custo dos produtos)
  • Produtos mais vendidos
  • Estoque baixo e produtos parados
  • Vendas recentes

Os valores de lucro consideram o custo unitário cadastrado no produto.
